# CalorieDaily

Aplicación web moderna para convertir BMR, TDEE y objetivos físicos en un plan diario práctico de alimentación, ejercicio y seguimiento de progreso.

## Desarrollo

- `npm install`
- `npm run lint`
- `npm run build`
- `npm run preview`

## Deploy en Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Los deploy previews usan la misma configuración definida en `netlify.toml`
